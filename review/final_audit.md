## Reproducibility
* **One-command rebuild.** `python code/run_all.py --mode full` reruns every stage:
  * the experiments, including `amendment2` and `posthoc`;
  * the aggregation;
  * the figures and the paper build (stage `paper`).
* **Bit-identical re-run.** A fresh-clone re-run of one fresh data set reproduced all 240 result rows
  exactly.
* **Tests.** 15 pipeline unit tests and 11 tool tests pass.
* **Tool validation.** The tool, validated on 20 files downloaded afresh, matches the pipeline:
  verdicts 20/20, coverage within 2 SE 20/20.
* **Known dependencies.** OpenML and UCI must remain available, or the data cache must be archived
  with the code (author action).
