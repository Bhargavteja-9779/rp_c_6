## 2. Reproducibility audit (Phase 21), executed as a fresh-clone test

1. `git clone` of the repository into an empty directory, with no local data cache.
2. `python -m pytest -q tests` → **11 passed**.
3. `python run_all.py --mode full --stage analyze` (datasets downloaded afresh from OpenML) → `statistics.json` regenerated with **0 differences** from the committed file (recursive comparison, tolerance 1e-12).
4. Full re-run of one dataset (kc1, 1,200 result rows: 10 seeds × 2 protocols × 5 learners × 2 scores × 3 α × methods) → **bit-identical** to the committed raw file (maximum absolute difference 0.0).

Not re-run from scratch: the complete 103-dataset grid (≈2 h), the injection (≈2 h) and the capacity experiments (≈1 h) on 4 cores. Determinism is established for one dataset and the analysis layer; full regeneration takes about 5 CPU-hours × 4.

Requirements: Python 3.13, pinned packages (`code/requirements.txt`), internet access to openml.org. Building the manuscript also needs pandoc 3.1 and Chromium (PDF) or Word (DOCX).
